01Purposescope - 119 words

Turn the manual 2026-09-30 job-application day into one repeatable, auditable, unattended daily run on Mac Mini 1 (MM1): source new HiringCafe AI roles, apply, email two director-level contacts per applied job from gblack686@gmail.com with the resume attached, and archive every event. The build ships the cron disarmed. This document is a plan only; nothing here is built, applied, armed, or sent.

1archive row per job event and per email event
2emails per applied job (director-level)
50maximum real sends per day, dry runs never counted

Success test. For any run date, the Telegram summary, Gmail Sent, the send receipts, and the Supabase archive agree on the same counts, and no day exceeds 50 real sends.

02Problemgap - 222 words

The 2026-09-30 run worked, but only because an operator session held it together. Evidence from the committed snapshot (branch feat/job-outreach-snapshot-20260930, PR #1386, folder artifacts/job-outreach/2026-09-30/):

  • 20 job receipts: 8 applied, 8 skipped (expired), 4 manual_gate (Workday and iCIMS account walls, plus a Dell code step that needed a human).
  • 42 Gmail send receipts in one folder: 22 real sends, 19 dry runs, 1 denied. A naive file count would report 42 and trip a 50 cap early; the cap must count only dry_run=false and status=ok.
  • The apply tooling was ad-hoc CDP scripts in MM1 /tmp (cdp.mjs, cdpt.mjs, fill.mjs, receipt.mjs, verify_email.py). MM1 is not a git checkout, so none of it was versioned; receipts lived only on MM1 until the snapshot PR.
  • Drafts lived in a session scratchpad; the queue (outreach_queue.json) held 23 contacts: 8 verified, 12 pattern-likely, 3 unconfirmed.
  • The two existing skills are stale: hiringcafe-apply is a Playwright pipeline for Greenhouse and Ashby with a $150K target, and hiringcafe-job-scraper only scrapes. Neither archives scraped jobs, applies via the persisted CDP session, or emails anyone.
  • gmail_send_policy.py gates recipients but has no daily cap, and personal-gmail/send.py cannot attach a file.
  • The Jev browser sidekick on MM1 has receipts and eligibility but no CDP driver, and submit is disabled by design.
