12Notes154 words - receipt

Data Safety

Browser snapshots must be read-only and static. They can include trace IDs, row IDs, timestamps, durations, statuses, summary text, and links. They must not include raw prompts, raw model outputs, OAuth data, service-role keys, local credential paths, or unbounded stderr/stdout.

Crossings Definition

For the first pass, a crossing is any row that records a transition or relationship boundary: cron tick to output, PRD to Kanban task, task/run status family, host receipt lifecycle, or trace linkage.

Repo and Directory Filters

The filter model should include repo_slug and dir_path immediately because agent_runs was designed for those fields.

Supabase Writes

This plan does not require new writes to Supabase for phase one. Missing rows should be backfilled with service-role scripts that produce readback receipts, then published only as sanitized static JSON.
